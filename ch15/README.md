# 关于 `ch15_example15_1_GA.m`。

---

## 脚本结构说明

脚本共分9个功能模块，完整复现例15-1并与教材最小二乘法进行对比：

| 模块 | 内容 |
|---|---|
| 1 | 定义结构参数（M矩阵、名义刚度k₀） |
| 2 | 计算损伤状态下的"实测"角频率 ωᵈ（预设k₃折减20%） |
| 3 | 定义目标函数 J(α) = ‖ω(α)−ωᵈ‖²（匿名函数形式） |
| 4 | 配置GA参数（种群100、最大200代、交叉率0.8、自适应变异） |
| 5 | 调用 `ga()` 函数运行，实时绘制最优适应度收敛曲线 |
| 6 | 打印识别结果与各参数相对误差 |
| 7 | 对比理论频率与识别后频率（验证反演精度） |
| 8 | 绘制损伤参数识别结果柱状图（真实值 vs GA识别值） |
| 9 | 与教材最小二乘灵敏度法的文字对比分析 |
| 辅助函数 | `compute_frequencies(alpha, k0, M)`：计算任意损伤参数下的三阶角频率 |

---

## 关键设计说明

**物理约束的加入**（对应教材思考题2的要求）：通过 `lb = [0,0,0]` 和 `ub = [1,1,1]` 直接传入 `ga()` 函数，确保所有候选解均满足 `0 ≤ αⱼ ≤ 1`，从根本上杜绝刚度"增加"或"超量损伤"的无物理意义解。

**随机种子固定**：使用 `rng(42)` 保证每次运行结果可复现，便于教学演示。

**运行环境要求**：需要 Matlab **Global Optimization Toolbox**（该工具箱包含 `ga`、`gamultiobj` 等函数），在 Matlab R2016b 及以上版本均可运行。
